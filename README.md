# Тестовые программы

Данный набор программ используется для демонстрации работы механизмов операционных систем.

# Содержание
## Программы для тем по многопоточности, организации памяти и пользовательского пространства
1. Программа для демонстрации логического адресного пространства в ОС (`address_test`)
2. Программа для демонстрации количества сегментов для одного адреса (`segments`)
3. Программа для демонстрации гонки данных (`threads_race`)
4. Программа для демонстрации механизма библиотек (`library_linking`)

## Программы для темы по межпроцессному взаимодействию (IPC)
1. Программа для демонстрации работы механизма сигналов в ОС (`signals`)
2. Программы для демонстрации работы механизма именованных каналов в ОС (`fifos`)
3. Программы для демонстрации работы механизма сокетов в ОС (`sockets`)
4. Программы для демонстрации работы механизма анонимных каналов в ОС (`pipes`)
5. Программы для демонстрации работы механизма разделяемой памяти в ОС (`shared_memory`)

*Примечание:* программы #4 и #5 работают только в среде ОС Unix или ОС на базе ядра Linux.
